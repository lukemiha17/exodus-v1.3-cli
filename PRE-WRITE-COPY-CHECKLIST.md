# Pre-Write Copy Checklist

**Rule (Lucas, 2026-06-03):** Ask these **every time** you're about to write an ad (copy / genesis). Offer them as a quick menu — but they must **never block**. If Lucas doesn't want to answer one, run a sensible default and go.

## The 6 questions
1. **Segment** — which segment is this for?
2. **Awareness level** — what awareness level? (`unaware · problem-aware · solution-aware · product-aware`)
3. **Primer** — which primer? *(Do NOT decide in advance — ask, and Lucas will tell you.)* [#44 / #46]
4. **Mechanism** — what mechanism should it use?
5. **CTA** — what are you driving people to / where's it going? [#54]
6. **Overall guidelines** — any steering from Lucas?

## Default rule (critical) [#52]
- The questions are **offered, never required**.
- "Really important" that they never block the write.
- If any answer is skipped → run the default for that field and proceed.

## Notes
- Mirrors the image-side rule that **steering must be asked, never authored for him** (see `exodus-v1.3-cli-edits.md` A7/A11 and the steering #1-requirement note).
- Applies to: `genesis run --brief`, `idea write`, organic/swipe → write, brief-from-seeds — anything that produces copy.
